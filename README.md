# Contestly

공모전을 발견하고, 마감 일정과 지원 준비 과정을 한곳에서 관리하는 정적 웹 서비스입니다.

## 주요 기능

- 씽굿의 접수 중·마감 임박·접수 예정 공모전 일일 자동 수집
- 제목, 주최 기관, 분야, 응모 대상 통합 검색
- 분야, 응모 대상, 남은 기간 상세 필터
- 브라우저에 저장되는 공모전 찜하기
- 마감일 캘린더 파일(`.ics`) 내보내기
- 관심·자료 조사·제작 중·제출 완료 단계별 도전 보드
- 공모전별 메모와 5단계 준비 체크리스트

## 로컬 실행

브라우저의 `fetch` 요청이 동작하도록 프로젝트 루트에서 정적 서버를 실행합니다.

```powershell
py -3 -m http.server 8000
```

그다음 `http://localhost:8000`으로 접속합니다.

## 데이터 갱신

```powershell
py -3 -m pip install requests
py -3 scripts/scrape.py
```

수집 결과는 `data/contests.json`에 안전하게 교체 저장됩니다. GitHub Actions의 `Daily Contest Update` 워크플로가 매일 같은 작업을 수행합니다.

## 저장 방식

찜, 진행 상태, 메모, 체크리스트는 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제나 다른 기기 사용 시 자동으로 동기화되지 않습니다.
